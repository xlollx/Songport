<p>音楽サービス間でプレイリストを同じ内容に保てます。手作業で作り直す必要はありません。すべてスマートフォン上で動作します：アカウントもサーバーも広告もトラッキングもありません。</p>
<ul>
<li>同期元と同期先のプレイリストを選ぶか、同期先をアプリに作成させることができます</li>
<li>手動またはスケジュールで同期：1時間ごと、6時間ごと、毎日、毎週</li>
<li>追加のみ、または削除も反映</li>
<li>お気に入りの曲を同期元として使用</li>
<li>見つからなかった曲を確認：ワンタップで使える候補、有力な結果から順に表示、同期元のアルバムの曲、または曲のリンクを貼り付け</li>
<li>API のないサービス向けに、プレイリストファイル（CSV、M3U、iTunes XML、JSON）のインポートとエクスポート</li>
<li>アカウント全体を日付付きのバージョンとしてバックアップ、重複の削除</li>
</ul>
<p>Spotify、Apple Music、YouTube Music、TIDAL、Deezer、Subsonic/Navidrome・Jellyfin・Plex サーバー、同期元としての Last.fm と ListenBrainz、そしてファイルに対応しています。開発者キーが必要なサービスは、アプリ内のガイドに沿って設定できます。キーとすべてのアクセストークンは端末上で暗号化されたまま保存されます。</p>
<p>YouTube Music、Amazon Music、および開発者キーなしでの Spotify と Apple Music へのサインインは、アプリに組み込まれた各サービス自身のウェブプレーヤーを通じて動作します。これらは公式 API ではないため、最初のサインインの前にアプリが注意事項を表示します。</p>
<p>Songport はこれらのサービスのいずれとも提携していません。サービス名は互換性を示す目的でのみ使用しています。</p>
